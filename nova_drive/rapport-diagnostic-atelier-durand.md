# Rapport de Diagnostic Organisationnel

**Client :** Atelier Durand  
**Secteur :** Industrie agroalimentaire  
**Effectif :** 182 salariés  
**Période :** Septembre - Novembre 2024  
**Consultant référent :** Marie Dubois  
**Confidentialité :** Diffusion restreinte COMEX

---

## Synthèse exécutive

Atelier Durand, PME familiale en croissance (+15%/an depuis 2021), fait face à des tensions organisationnelles liées à sa taille critique. Le passage de 120 à 180 salariés en 3 ans n'a pas été accompagné d'une évolution des modes de gouvernance et de pilotage.

**Constat principal :** L'entreprise fonctionne encore avec des habitudes de "petite structure" alors que sa complexité exige une organisation professionnalisée.

**Recommandation prioritaire :** Mettre en place une direction opérationnelle déléguée et digitaliser les processus de planification.

---

## 1. Contexte et méthodologie

### 1.1 Contexte

- Croissance externe (acquisition d'un concurrent en 2023)
- Passage de 1 à 3 sites de production
- Direction générale toujours assurée par le fondateur (62 ans)

### 1.2 Méthodologie

| Étape                | Réalisation                                                          |
| -------------------- | -------------------------------------------------------------------- |
| Entretiens           | 22 entretiens individuels (DG, managers, opérationnels, CHSCT)       |
| Ateliers             | 3 ateliers collectifs (cartographie processus, irritants, priorités) |
| Analyse documentaire | Organigrammes, procédures, rapports d'activité 2022-2024             |

---

## 2. Constats majeurs

### 2.1 Gouvernance et pilotage

| Constat                                           | Impact                                            | Gravité |
| ------------------------------------------------- | ------------------------------------------------- | ------- |
| Toutes les décisions &gt; 10k€ validées par le DG | Délai moyen 3 semaines, frustration managers      | Élevée  |
| Pas de comité de direction opérationnel           | Désalignement entre sites, doublons d'initiatives | Élevée  |
| Réunions de pilotage non structurées              | Pas de suivi des actions, décisions oubliées      | Moyenne |

### 2.2 Processus opérationnels

| Constat                                       | Impact                                               | Gravité |
| --------------------------------------------- | ---------------------------------------------------- | ------- |
| Planification production sur Excel partagé    | Conflits de version, erreurs de planning             | Élevée  |
| Pas de processus de demande d'achat formalisé | Dépassements budgétaires fréquents                   | Moyenne |
| SAV géré par téléphone + papier               | Perte de traçabilité, délais de traitement 5-7 jours | Élevée  |

### 2.3 Système d'information

| Constat                                             | Impact                              | Gravité |
| --------------------------------------------------- | ----------------------------------- | ------- |
| ERP existant sous-utilisé (30% des fonctionnalités) | Double saisie, données incohérentes | Élevée  |
| Shadow IT important (15 outils non déclarés)        | Risque sécurité, perte de données   | Moyenne |
| Pas d'interconnexion entre outils                   | Saisies manuelles, erreurs          | Moyenne |

### 2.4 Culture et management

| Constat                                                   | Impact                                       | Gravité |
| --------------------------------------------------------- | -------------------------------------------- | ------- |
| Communication descendante uniquement                      | Rumeurs, défiance vis-àrence des changements | Moyenne |
| Managers opérationnels débordés, pas formés au management | Turnover 25% chez les chefs d'équipe         | Élevée  |
| Peu de reconnaissance des initiatives terrain             | Démotivation, "on fait le minimum"           | Moyenne |

## 4. Recommandations

### Chantier 1 : Digitalisation planification production (Quick Win)

**Objectif :** Remplacer Excel par un outil de planning partagé en temps réel

| Élément             | Détail                                    |
| ------------------- | ----------------------------------------- |
| Solution envisagée  | PlanetTogether ou équivalent              |
| Budget estimé       | 15-20k€ + 3 jours de formation            |
| Délai               | 2 mois                                    |
| Responsable suggéré | Directeur industriel                      |
| ROI attendu         | -30% temps de planification, -50% erreurs |

### Chantier 2 : Reorganisation direction opérationnelle (Structurant)

**Objectif :** Passer d'une direction centralisée à une direction déléguée par site

| Élément      | Détail                                                                                     |
| ------------ | ------------------------------------------------------------------------------------------ |
| Actions clés | Nommer un directeur de site par site, créer un CODIR hebdo, définir des seuils de décision |
| Budget       | Coaching DG + formation managers (30-40k€)                                                 |
| Délai        | 6 mois                                                                                     |
| Prérequis    | Volonté forte du DG de déléguer                                                            |

### Chantier 3 : Rituel de pilotage standardisé (Quick Win)

**Objectif :** Mettre en place des réunions de pilotage efficaces avec suivi des actions

| Élément      | Détail                                                             |
| ------------ | ------------------------------------------------------------------ |
| Actions clés | Template ordre du jour, compte-rendu type, tableau de bord partagé |
| Budget       | 5k€ (accompagnement)                                               |
| Délai        | 1 mois                                                             |
| ROI          | Décisions traçables, -50% réunions inutiles                        |

### Chantier 4 : Refonte processus achats (Structurant)

**Objectif :** Formaliser et digitaliser le processus de demande d'achat

| Élément      | Détail                                                            |
| ------------ | ----------------------------------------------------------------- |
| Actions clés | Workflow de validation, seuils par niveau, catalogue fournisseurs |
| Budget       | 10-15k€ (outil + paramétrage)                                     |
| Délai        | 3 mois                                                            |
| ROI          | -20% dépassements budgétaires                                     |
