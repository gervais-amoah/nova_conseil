# Politique de Formation et Développement

**Service :** RH  
**Responsable :** Sophie Martin, Responsable RH  
**Validation :** Direction  
**Dernière mise à jour :** Février 2024

---

## 1. Principes

| Principe          | Application                                                     |
| ----------------- | --------------------------------------------------------------- |
| Investissement    | 3% de la masse salariale annuelle consacrée à la formation      |
| Individualisation | Plan de développement par salarié, revu annuellement            |
| Utilité           | Formation alignée sur les besoins du cabinet et les aspirations |
| Transmission      | Chaque formation suivie = restitution à l'équipe                |

---

## 2. Budget et allocation

| Profil            | Budget annuel | Modalités                                |
| ----------------- | ------------- | ---------------------------------------- |
| Consultant junior | 2 500 €       | Formations méthodologiques, techniques   |
| Consultant senior | 3 500 €       | Expertise sectorielle, management        |
| Manager / Associé | 5 000 €       | Leadership, développement cabinet        |
| Support           | 2 000 €       | Outils, langues, compétences transverses |

**Règle :** Budget non utilisé non reportable, sauf accord direction.

---

## 3. Types de formation

### Formations internes

| Type                        | Organisateur             | Fréquence     |
| --------------------------- | ------------------------ | ------------- |
| Formation méthodologie      | Consultants seniors      | Mensuelle     |
| Retour d'expérience mission | Consultant de la mission | Trimestrielle |
| Veille sectorielle          | Rotation équipe          | Bimestrielle  |
| Formation outils            | Support / IT             | Selon besoins |

### Formations externes

| Type              | Exemples                         | Budget type     |
| ----------------- | -------------------------------- | --------------- |
| Certification     | ICF coaching, PMP, Prince2       | 3 000 - 6 000 € |
| Conférences       | HUB Institute, Big Boss Festival | 500 - 1 500 €   |
| Cours spécialisés | Data, IA, sectoriel              | 1 000 - 3 000 € |
| Langues           | Anglais, espagnol                | 800 - 1 500 €   |

---

## 4. Processus de demande

Identification besoin (salarié ou manager)
↓
Discussion en entretien annuel ou point trimestriel
↓
Recherche formation, comparaison (contenu, coût, dates)
↓
Validation manager + RH (budget disponible)
↓
Inscription, calage avec planning missions
↓
Participation formation
↓
Restitution équipe (présentation, note synthèse)
↓
Évaluation à 3 mois (application concrète)

---

## 5. Plan de développement individuel

| Élément               | Contenu                                     |
| --------------------- | ------------------------------------------- |
| Compétences actuelles | Auto-évaluation + évaluation manager        |
| Objectifs 12 mois     | Compétences à acquérir, évolution souhaitée |
| Actions               | Formations, missions ciblées, mentorat      |
| Suivi                 | Points trimestriels, ajustements            |

---

## 6. Évolution de carrière

| Horizon | Parcours type                                       |
| ------- | --------------------------------------------------- |
| 0-2 ans | Consultant junior → Consultant confirmé             |
| 2-5 ans | Consultant confirmé → Senior, expertise sectorielle |
| 5-8 ans | Senior → Manager, pilotage équipe                   |
| 8+ ans  | Manager → Associé, développement cabinet            |

**Alternatives :** Expertise technique (pas de management), direction de projet client, intrapreneuriat.
