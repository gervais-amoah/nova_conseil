# Processus d'Onboarding — Nouveau Consultant

**Service :** RH  
**Responsable :** Sophie Martin, Responsable RH  
**Dernière mise à jour :** Mars 2024

---

## 1. Objectif

Permettre à un nouveau consultant d'être opérationnel en 4 semaines, avec une compréhension claire du cabinet, de ses méthodes et de ses outils.

---

## 2. Semaine 1 : Découverte

| Jour     | Activités                                                                 | Interlocuteur         |
| -------- | ------------------------------------------------------------------------- | --------------------- |
| Lundi    | Accueil administratif, badge, matériel, accès outils                      | RH + IT               |
| Lundi    | Présentation cabinet : histoire, valeurs, organisation, équipes           | DG                    |
| Mardi    | Présentation méthodologies : diagnostic, conduite du changement, coaching | Directrice Consulting |
| Mercredi | Tour des locaux, présentation équipe, café informel                       | Parrain/marraine      |
| Jeudi    | Formation outils : Drive, CRM, gestion de projet, facturation             | Responsable Support   |
| Vendredi | Point mi-parcours, questions, ajustements                                 | RH                    |

**Livrable fin S1 :** Checklist accès validée, présentations effectuées.

---

## 3. Semaine 2 : Immersion

| Jour     | Activités                                                    | Objectif                     |
| -------- | ------------------------------------------------------------ | ---------------------------- |
| Lundi    | Lecture des playbooks méthodologiques                        | Compréhension approche Novae |
| Mardi    | Étude de cas : rapport de diagnostic récent (anonymisé)      | Appréhension livrable type   |
| Mercredi | Shadowing : accompagnement d'un consultant senior en mission | Observation terrain          |
| Jeudi    | Shadowing : participation à un atelier client                | Observation facilitation     |
| Vendredi | Débrief shadowing, questions, retour d'expérience            | Parrain/marraine             |

**Livrable fin S2 :** Fiche de lecture playbook, compte-rendu shadowing.

---

## 4. Semaine 3 : Première production

| Jour           | Activités                                       | Objectif              |
| -------------- | ----------------------------------------------- | --------------------- |
| Lundi          | Attribution première mission (périmètre réduit) | Mise en pratique      |
| Mardi-Mercredi | Production : entretiens, analyse, rédaction     | Autonomie progressive |
| Jeudi          | Revue de production avec consultant senior      | Feedback constructif  |
| Vendredi       | Ajustements, validation, planification S4       | Consolidation         |

**Livrable fin S3 :** Première production validée.

---

## 5. Semaine 4 : Consolidation

| Jour     | Activités                                                             | Objectif                |
| -------- | --------------------------------------------------------------------- | ----------------------- |
| Lundi    | Formation commerciale : réponse à appels d'offres, rédaction propales | Compétences avant-vente |
| Mardi    | Participation réunion d'agence : présentation, échanges               | Intégration équipe      |
| Mercredi | Point bilan avec manager                                              | Évaluation, ajustements |
| Jeudi    | Définition objectifs 3 premiers mois                                  | Trajectoire claire      |
| Vendredi | Validation fin onboarding                                             | Autonomie confirmée     |

**Livrable fin S4 :** Plan d'objectifs signé, fin de période d'accompagnement renforcé.

---

## 6. Rôle du parrain/marraine

| Responsabilité | Détail                                               |
| -------------- | ---------------------------------------------------- |
| Accueil        | Présentation équipe, codes, traditions               |
| Disponibilité  | Réponse questions sous 24h, temps de parole hebdo    |
| Feedback       | Retour régulier sur productions, comportements       |
| Intégration    | Invitations déjeuners, événements, moments informels |

**Profil type :** Consultant senior, même pôle, 2+ ans d'ancienneté.

---

## 7. Outils et accès à préparer

| Catégorie     | Éléments                                               |
| ------------- | ------------------------------------------------------ |
| Matériel      | Laptop, badge, téléphone si nécessaire                 |
| Accès         | Drive, CRM, outil de gestion de projet, messagerie     |
| Documentation | Playbooks, templates, rapports types, grille tarifaire |
| Contacts      | Annuaire interne, clients du périmètre                 |

---

## 8. Indicateurs de réussite

| Indicateur                                      | Cible           |
| ----------------------------------------------- | --------------- |
| Temps avant première mission autonome           | &lt; 6 semaines |
| Satisfaction nouveau consultant (questionnaire) | &gt; 4/5        |
| Rétention à 6 mois                              | 100%            |
| Évaluation manager à 3 mois                     | Satisfaisant    |
